## 6. ZABRANJENE OVISNOSTI

Dozvoljeni smjerovi:

- `apps/web` → `packages/ui` i `packages/api-client`.
- `apps/api` → `packages/backend`.
- `apps/worker` → `packages/backend`.
- `packages/api-client` nastaje iz OpenAPI ugovora.

Zabranjeno:

- `apps/web` → PostgreSQL.
- `apps/web` → Dovecot/Postfix.
- `apps/worker` → FastAPI HTTP route moduli.
- `packages/backend` → Next.js ili React.
- `packages/backend` → produkcijske IMAP/SMTP implementacije.

Uvesti automatiziranu provjeru ovih pravila.

## 7. FAIL-CLOSED KONFIGURACIJA

Razvojne konfiguracije moraju podrazumijevati mock-only način rada:

```dotenv
APP_ENV=development
MAIL_ADAPTER_MODE=mock
SMTP_ADAPTER_MODE=mock
ADMIN_AGENT_MODE=mock
```

Ako je konfiguracija nepoznata, nepotpuna ili nedopuštena, aplikacija ne smije aktivirati vanjski adapter.

U T01 se ne implementira stvarni IMAP, SMTP ni Admin Agent adapter.
