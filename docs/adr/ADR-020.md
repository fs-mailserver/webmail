Usvajamo sljedeći sigurnosni model:

- **Super Admin i Admin:** obvezan MFA.
- **User:** MFA opcionalan, osim ako administrator odredi drukčije.
- **Autentifikacija:** server-side sesije, TOTP i jednokratni recovery kodovi.
- **Sesije:** HttpOnly, Secure cookies, mogućnost trenutnog opoziva i evidencija aktivnih uređaja.

### Sigurnosna pravila

| Područje | Pravilo |
|---|---|
| Lozinke | Argon2id hash |
| Sesije | HttpOnly, Secure, SameSite cookies |
| Autorizacija | Provjera uloge i pristupa svakom mailboxu |
| MFA | TOTP i recovery kodovi |
| Admin operacije | Ponovna autentifikacija za osjetljive radnje |
| WebSocket | Autentifikacija i provjera prava |
| API | Rate limiting i validacija zahtjeva |
| HTML poruke | Izolirani prikaz, sanitizacija i blokiranje vanjskih resursa |
| Privitci | Izolirana obrada i ograničenje resursa |
| Audit | Evidencija prijava i administrativnih promjena |

Preporučujem **server-side sesije** s neprozirnim session ID-jem umjesto dugotrajnih JWT tokena spremljenih u pregledniku. To olakšava trenutačno ukidanje pristupa.

Za zajedničke mailboxe ukidanje prava mora prekinuti i pripadajuće WebSocket pretplate.
