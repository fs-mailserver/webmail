### Pravila koja predlažem

| Područje | Pravilo |
|---|---|
| API ključevi | Šifrirani, nikada dostupni frontendu |
| Modeli | Mogu se mijenjati kroz administratorske postavke |
| Automatska analiza | Posebno uključivanje za svaki mailbox |
| Troškovi | Evidencija tokena i procijenjenog troška |
| Limiti | Mjesečni limit po korisniku i mailboxu |
| Privatnost | Bez automatskog slanja sadržaja kada je AI isključen |
| Audit | Evidencija obrade bez pohranjivanja cjelokupnog sadržaja poruke |

Kod zajedničkih mailboxa potrebno je dodatno pravilo: automatsku analizu može uključiti samo korisnik s odgovarajućim administrativnim ovlastima, a obrađeni rezultati moraju poštovati prava pristupa.
