### 2. Predložena ograničenja

Ovo su početne razvojne vrijednosti, a ne trenutno potvrđena ograničenja tvog produkcijskog mailservera.

| Parametar | Prijedlog |
|---|---:|
| Maksimalna SMTP/MIME poruka | 50 MiB |
| Jedan privitak | 35 MiB |
| Broj privitaka po poruci | 25 |
| Paralelni uploadi po korisniku | 3 |
| Nezavršeni upload | Brisanje nakon 24 sata |
| Dovecot mailbox kvota | Individualno po mailboxu |
| Ograničenje Webmail storagea | Centralni Storage Manager |

Zašto je veličina privitka manja od veličine poruke?

Zato što se binarni privitci pri slanju standardnim MIME postupkom najčešće kodiraju u Base64, čime se veličina povećava približno za trećinu. Dodatni prostor zauzimaju MIME zaglavlja i tijelo poruke.

### 3. Sigurnosna pravila

- Privitci se prenose streaming metodom, bez učitavanja cijele datoteke u memoriju FastAPI procesa.
- Nazivi datoteka ne koriste se kao stvarne putanje za spremanje.
- Sadržaj se validira neovisno o ekstenziji.
- HTML i potencijalno aktivni sadržaj ne izvršavaju se pri pregledu.
- Privremene datoteke imaju vremenski rok i vlasnika.
- Veliki uploadi podliježu globalnom Storage Manageru.
- Webmail provjerava ograničenja prije slanja, ali Postfix ostaje konačni autoritet za SMTP prihvaćanje.

Postojeću Postfix konfiguraciju nećemo automatski povećavati samo zato što Webmail podržava veće datoteke.
