## Korak 105 — ADR-105: Nextcloud integracija, WebDAV i upravljanje dijeljenim datotekama

Sada definiramo **Nextcloud Integration Service**, koji će povezivati naš Next.js/FastAPI Webmail s postojećim Nextcloud serverom.

Želimo omogućiti tri osnovne funkcionalnosti: slanje velikih datoteka, prilaganje postojećih Nextcloud datoteka e-mailovima i upravljanje poveznicama koje smo prethodno poslali.

### 4. Posebno važno: odvajanje korisničkih datoteka

Ne želimo da jedan Webmail korisnik dobije pristup datotekama drugih korisnika samo zato što svi koriste isti Nextcloud server.

Predlažem sljedeća pravila:

| Područje | Sigurnosna politika |
|---|---|
| Webmail korisnik | Vidi samo autorizirane Nextcloud datoteke |
| Servisni račun | Minimalna potrebna prava |
| Vjerodajnice | Secrets Manager iz ADR-069 |
| WebDAV pristup | Isključivo preko backend servisa |
| Share poveznice | Evidentirane i povezane s ovlaštenim vlasnikom |
| Opoziv Webmail korisnika | Blokira nove zahtjeve preko Webmaila |
| Izravni Nextcloud pristup | Podliježe zasebnoj Nextcloud autorizaciji |

Ako korisniku ukinemo pristup Webmailu, postojeće javne poveznice neće nužno automatski prestati vrijediti. Zato moramo definirati zaseban postupak provjere i opoziva dijeljenja pri offboardingu iz ADR-084.

### 5. Životni ciklus dijeljenih datoteka

Predlažem statuse:

| Status | Značenje |
|---|---|
| `uploading` | Datoteka se prenosi |
| `scanning` | Sigurnosna provjera |
| `ready` | Datoteka spremna za dijeljenje |
| `shared` | Poveznica aktivna |
| `expired` | Poveznica istekla |
| `revoked` | Dijeljenje opozvano |
| `failed` | Operacija nije uspjela |

Statusi u Webmailu moraju se usklađivati sa stvarnim Nextcloud stanjem. Nećemo prikazivati poveznicu kao aktivnu ako Nextcloud potvrdi da je opozvana.

Za datoteke koje su još potrebne drugim korisnicima ili drugim aplikacijama ne smijemo automatski provoditi brisanje samo zato što je Webmail poveznica istekla.

### 6. Što ako Nextcloud nije dostupan?

U tom slučaju Webmail treba nastaviti normalno čitati i slati obične e-mailove.

Funkcionalnost velikih privitaka bit će privremeno nedostupna, a nedovršeni upload ostaje u kontroliranom statusu za siguran nastavak ili otkazivanje.

**Nextcloud ne smije postati kritična ovisnost osnovnog rada Dovecota, Postfixa ili Webmail Inboxa.**
