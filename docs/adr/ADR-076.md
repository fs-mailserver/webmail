## Korak 76 — ADR-076: Kapacitet, performanse i skaliranje Webmail sustava

Sada definiramo kako će novi Webmail učinkovito raditi s velikim mailboxima, brojnim porukama, privicima i istodobnim korisnicima.

Budući da će sustav raditi na postojećem dedicated serveru zajedno s Docker Mailserverom i drugim aplikacijama, **Webmail ne smije iscrpiti resurse potrebne za dostavu pošte**.

### 2. Ciljevi performansi

Predlažem početne ciljeve za testiranje, ne obećane rezultate:

| Operacija | Ciljani p95 |
|---|---:|
| Otvaranje već indeksiranog Inboxa | do 500 ms |
| Prikaz indeksiranog razgovora | do 700 ms |
| Promjena pročitanosti poruke | do 500 ms |
| Pretraga pošiljatelja ili naslova | do 1 s |
| Full-text pretraga | do 2 s |
| Command Palette | do 150 ms |
| Dostava WebSocket događaja | do 1 s nakon detekcije |

Mjerit ćemo vrijeme pod jasno definiranim opterećenjem. Za IMAP operacije potrebno je zasebno razlikovati brzinu lokalnog UI odziva od potvrde promjene na Dovecotu.

### 3. Zaštita ostalih servisa

Predlažem odvojene proračune resursa:

| Komponenta | Politika |
|---|---|
| Postfix / Dovecot | Zaštićen prioritet u odnosu na Webmail obradu |
| FastAPI | Ograničen broj workera i konekcija |
| PostgreSQL | Centralno upravljanje konekcijama |
| IMAP pool | Dinamička ograničenja iz ADR-032 |
| AI Workers | Stroge kvote i backpressure |
| Extractor privitaka | Ograničenje RAM-a, CPU-a i vremena |
| Historical backfill | Smanjivanje aktivnosti pod opterećenjem |
| Redis | Ograničenje memorije i definirana politika podataka |

Nećemo sada određivati konkretne CPU/RAM limite bez stvarnog mjerenja dostupnog kapaciteta i opterećenja servera.

### 5. Posebno važan slučaj: veliki mailboxi

Ako korisnik ima stotine tisuća poruka, nećemo pri prvom povezivanju čekati dovršetak cijele sinkronizacije.

To smo već riješili u ADR-033: najnovije poruke prikazuju se prve, a starija povijest indeksira se u pozadini.

U ADR-076 dodat ćemo automatsko smanjenje intenziteta indeksiranja kada CPU, memorija, disk ili Dovecot dosegnu zadane pragove.
