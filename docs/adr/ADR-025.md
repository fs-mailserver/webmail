## Korak 23 — ADR-025: Offline skice i sigurna sinkronizacija

Sada definiramo što se događa kada korisnik napiše e-mail bez internetske veze, zatvori preglednik ili ponovno uspostavi vezu.

Najvažnije pravilo: **poruka se nikada ne smije automatski poslati samo zato što se internetska veza vratila.**

### Pravila sinkronizacije

| Situacija | Ponašanje |
|---|---|
| Korisnik piše offline | Lokalno spremanje u IndexedDB |
| Zatvori preglednik | Skica ostaje lokalno, ako preglednik sačuva podatke |
| Ponovno uspostavi vezu | Provjera sesije i sinkronizacija |
| Server ima noviju verziju | Konflikt — čuvaju se obje verzije |
| Korisnik izgubi pristup mailboxu | Sinkronizacija se odbija |
| Sesija je istekla | Potrebna ponovna prijava |
| Privitci nisu dostupni | Skica se označava nepotpunom |
| Sinkronizacija uspješna | Lokalna verzija dobiva potvrđeni server revision |

Za offline privitke postavit ćemo ograničenja veličine i provjeru dostupnog prostora. Ne smijemo obećati trajno čuvanje ako korisnik obriše podatke preglednika ili operativni sustav ukloni lokalnu pohranu.
