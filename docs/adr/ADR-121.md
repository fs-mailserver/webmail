## 3. Što mora sadržavati prva verzija?

Predlažem da **Faza 1** ima jasno definirane minimalne funkcionalnosti.

| Modul | Obvezno za prvu verziju |
|---|---|
| Authentication | Passkey, lozinka + MFA, sessions |
| Authorization | RBAC i per-mailbox ACL |
| IMAP | Sigurna sinkronizacija s Dovecotom |
| Inbox | Liste, mape, čitanje, oznake |
| Composer | Slanje, odgovori, prosljeđivanje, nacrti |
| Privitci | Sigurno preuzimanje i antivirusna kontrola |
| Search | PostgreSQL FTS |
| Admin | Korisnici, mailboxi i osnovna administracija |
| UI | Next.js, Light/Dark, šest jezika |
| Security | Audit, CSRF, rate limits, sigurnosna izolacija |
| Operations | Backup, monitoring, restore testovi |

Svi potrebni sigurnosni temelji iz ranijih ADR-ova ostaju obvezni bez obzira na fazu.

**Prva verzija ne mora odmah zamijeniti SnappyMail.** Prema ADR-082, prelazak se obavlja jednokratno, tek nakon potpunih testova i zasebnog odobrenja.

## 4. Ključna arhitekturna pravila

Ovih šest pravila predlažem kao nepromjenjive temelje cijele platforme:

| Pravilo | Zahtjev |
|---|---|
| Dovecot authoritative | Izvorne e-mail poruke ostaju u Dovecotu |
| PostgreSQL application data | Indeksi i aplikacijski podaci ostaju odvojeni od originalnih poruka |
| Default-deny authorization | Nijedan pristup bez izričite ovlasti |
| Mailserver protection | Webmail workeri ne smiju ugroziti Postfix ili Dovecot |
| Reversible rollout | Bez migracije produkcije prije provjerenog plana povratka |
| Explicit GO | Nema automatskog mergea, deploymenta ili cutovera |

## 5. Što formalna revizija mora utvrditi?

ADR-120 zahtijeva stvarnu provjeru, a ne samo potvrdu tablice.

Predlažem izradu jedinstvene **Architecture Review Matrix** za svih 120 ADR-ova, koja mora utvrditi:

- Sukobe između odluka, nedostajuće API ugovore i nejasno definirane vlasnike podataka.
- Obvezne ovisnosti pojedine razvojne faze.
- Sigurnosne uvjete koji se ne smiju odgoditi.
- Testne scenarije, kriterije prihvaćanja i rizike migracije.

Trenutačno imamo arhitekturni plan. Nemamo dokaz da su sve odluke već tehnički verificirane na stvarnoj infrastrukturi.
