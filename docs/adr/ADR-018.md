### Pravila pohrane

| Element | Gdje se nalazi |
|---|---|
| Originalna e-mail poruka | Dovecot Maildir |
| Indeksirana kopija `.eml` | Disk Webmaila |
| Tijelo poruke | PostgreSQL |
| Metapodaci i zastavice | PostgreSQL |
| Privitci | Disk, uz SHA-256 deduplikaciju |
| Tekst iz PDF/DOCX/XLSX | PostgreSQL |
| Backup | Postojeći sustav backupa, uz usklađenu obnovu |

Deduplikaciju bih ograničio na sadržaj unutar sigurnosne granice pojedinog mailboxa. Tako se izbjegava nepotrebno povezivanje podataka različitih korisnika.

Važno: **Webmail indeks nije zamjena za backup Dovecota.** Ako se poruka trajno obriše iz Maildira, ne smijemo se oslanjati na indeksiranu kopiju kao na jedini način oporavka.
