## Korak 99 — ADR-099: Napredno pretraživanje, operatori i spremljene pretrage

Sada projektiramo **Advanced Mail Search Engine**, koji omogućuje brzo pronalaženje poruka među svim autoriziranim mailboxima, uključujući višegodišnje arhive i sadržaj privitaka.

Već smo odlučili:

- **ADR-004:** PostgreSQL Full-Text Search.
- **ADR-014:** indeksiranje podržanih PDF, DOCX i XLSX privitaka.
- **ADR-047:** pretraga kroz više autoriziranih mailboxa.
- **ADR-055:** napredna pretraga povijesti kontakata i korespondencije.
- **ADR-080:** Dovecot ostaje autoritativna pohrana.

### 2. Operatori pretrage

Predlažem sintaksu sličnu onoj u naprednim e-mail klijentima.

| Operator | Primjer |
|---|---|
| Pošiljatelj | `from:info@example.com` |
| Primatelj | `to:office@example.com` |
| Naslov | `subject:račun` |
| Datum nakon | `after:2026-01-01` |
| Datum prije | `before:2026-12-31` |
| Privitci | `has:attachment` |
| Naziv datoteke | `filename:ugovor.pdf` |
| Nepročitano | `is:unread` |
| Označeno | `is:starred` |
| Mailbox | `in:mailbox-id` |
| Mapa | `folder:archive` |
| Minimalna veličina | `larger:10M` |

Podržat ćemo i kombiniranje uvjeta, navodnike za točne fraze te eksplicitne logičke operatore `AND`, `OR` i `NOT`.

Sintaksa će se pretvarati u parametrizirane upite, ne u proizvoljni SQL.

### 4. Pretraga sadržaja privitaka

Kao što smo definirali u ADR-014, izdvajanje teksta iz privitaka izvršava izolirani worker.

Pretraga će razlikovati:

| Vrsta rezultata | Izvor |
|---|---|
| Naslov i zaglavlja | Indeks poruke |
| Tijelo e-maila | Tekstualni MIME dijelovi |
| PDF | Izdvojeni tekst iz podržanih PDF-ova |
| DOCX | Izdvojeni tekst dokumenta |
| XLSX | Tekstualne vrijednosti ćelija |

OCR nećemo podrazumijevati za skenirane dokumente. To bi zahtijevalo zasebnu odluku o troškovima, opterećenju i privatnosti.

Privitci u antivirusnoj karanteni iz ADR-037 ne smiju se neovlašteno otvarati ni preuzimati kroz rezultate pretrage.

### 5. Spremljene pretrage i virtualne mape

Korisnik može spremiti upit kao virtualnu mapu.

Primjerice, „Računi 2026.” može prikazivati poruke koje odgovaraju određenim uvjetima, bez stvarnog premještanja poruka u Dovecotu.

Spremljeni upit ne daje trajno pravo pristupa rezultatima. Svakim otvaranjem ponovno se primjenjuju aktualne mailbox ovlasti.

### 6. Performanse i privatnost

Predlažem da pretraga koristi PostgreSQL GIN indekse, zasebnu optimizaciju metapodataka i ograničavanje složenosti korisničkih upita.

Za višejezičnost moramo testirati hrvatski, engleski, španjolski, njemački, talijanski i portugalski. Stemming, dijakritički znakovi i točne fraze moraju imati definirano ponašanje po jeziku.

Pretraga mora poštovati ADR-076, s ciljanim p95 do 2 sekunde za full-text upite pod dogovorenim testnim opterećenjem.

Rezultati ne smiju otkrivati sadržaj, isječke, broj pogodaka ni druge podatke iz neautoriziranih mailboxa.
