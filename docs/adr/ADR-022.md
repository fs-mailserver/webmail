### Glavni API moduli

| Modul | Primjer endpointa |
|---|---|
| Autentifikacija | `POST /api/v1/auth/login` |
| Sesije | `GET /api/v1/auth/sessions` |
| Korisnici | `GET /api/v1/users` |
| Mailboxi | `GET /api/v1/accounts` |
| Mape | `GET /api/v1/accounts/{id}/folders` |
| Poruke | `GET /api/v1/messages` |
| Threadovi | `GET /api/v1/threads/{id}` |
| Pretraga | `GET /api/v1/search` |
| Skice | `POST /api/v1/drafts` |
| Slanje | `POST /api/v1/messages/send` |
| AI | `POST /api/v1/ai/tasks` |
| Administracija | `POST /api/v1/admin/mailboxes` |
| WebSocket | `GET /ws` |

Svi endpointi provjeravaju autentifikaciju i prava pristupa na backendu. Identifikator mailboxa koji korisnik pošalje nije dokaz da smije pristupiti tom mailboxu.

### Važna tehnička pravila

- **Verzioniranje:** `/api/v1`, uz kompatibilne promjene unutar iste verzije.
- **Tipizacija:** TypeScript tipovi generirani iz FastAPI OpenAPI sheme.
- **Paginacija:** cursor/keyset za liste poruka i rezultate pretrage.
- **Idempotentnost:** obvezna za slanje poruka i kritične administrativne operacije.
- **Pogreške:** jedinstvena struktura odgovora s kodom, opisom i `request_id`.
- **WebSocket:** događaji s rednim brojem, autentifikacijom i ponovnom sinkronizacijom nakon prekida.
- **CSRF:** zaštita svih operacija koje mijenjaju stanje pri korištenju cookie sesija.
