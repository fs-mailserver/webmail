### 2. DKIM rotacija bez prekida slanja

Predlažem sljedeći postupak:

<list marker="number" connector="solid" gap={2}>
  <list-item>Mail Admin Agent priprema novi DKIM ključ i selektor, bez promjene aktivnog potpisa.</list-item>
  <list-item>Domain Manager prikazuje novi TXT zapis koji administrator ručno objavljuje u DNS-u.</list-item>
  <list-item>DNS Worker provjerava da je novi javni ključ vidljiv i odgovara pripremljenom privatnom ključu.</list-item>
  <list-item>Super Admin potvrđuje aktivaciju novog selektora.</list-item>
  <list-item>Stari javni ključ ostaje dostupan tijekom prijelaznog razdoblja, nakon čega se može povući uz novu potvrdu.</list-item>
</list>

Ako aktivacija ne uspije, sustav zadržava prethodnu konfiguraciju ili provodi kontrolirani rollback.

### 3. Što ćemo pratiti?

| Provjera | Predložena učestalost |
|---|---|
| MX, SPF, DKIM, DMARC | Svakih 6 sati |
| DNS promjene i odstupanja | Svakih 6 sati |
| PTR / forward-confirmed reverse DNS | Jednom dnevno |
| SMTP queue i deferred poruke | Svakih 5 minuta |
| Bounce i reject trendovi | Svakih 15 minuta |
| DKIM rotacija | Administratorski postupak, ne automatski po rasporedu |

Reputaciju IP adrese ne možemo pouzdano svesti na jedan univerzalni broj. Umjesto toga prikazivat ćemo stvarne SMTP odgovore, trendove odbijanja i eventualne podatke iz dostupnih reputacijskih servisa.

Posebno je važno da se **privremene SMTP pogreške (4xx)** razlikuju od **trajnih odbijanja (5xx)**, kako administrator ne bi dobivao pogrešne zaključke.

## ADR-042 — DKIM rotacija, DNS nadzor i reputacija odlazne pošte

### 2. Sigurna DKIM rotacija

Prema dokumentaciji Docker Mailservera, DKIM se može rotirati novim selektorom dok prethodni ključ ostaje dostupan za provjeru ranije potpisanih poruka. <Cite ref="turn958681search0"/>

Naš postupak:

1. Mail Admin Agent generira novi DKIM ključ, bez zamjene aktivnog.
2. Webmail prikazuje DNS TXT zapis za ručno objavljivanje.
3. DNS Worker provjerava objavljeni ključ.
4. Super Admin potvrđuje aktivaciju novog selektora.
5. Stari ključ ostaje tijekom prijelaznog razdoblja; njegovo povlačenje zasebno se potvrđuje.

Nema automatske rotacije ili brisanja aktivnog DKIM ključa bez odobrenja.

### 3. Kontinuirani nadzor

| Provjera | Predloženi interval |
|---|---|
| MX, SPF, DKIM, DMARC | 6 sati |
| PTR i DNS konzistentnost | 24 sata |
| Postfix queue | 5 minuta |
| SMTP bounce/reject trendovi | 15 minuta |
| DKIM status | 6 sati |
| Rotacija DKIM ključeva | Ručno odobrenje |

Možemo naknadno povezati Google Postmaster Tools API za dodatne podatke o isporuci prema Gmailu, ali njegova dostupnost metrika ovisi o podacima koje Google pruža. <Cite refs={["turn958681search6","turn958681search10"]}/>
