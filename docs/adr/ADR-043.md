## Korak 43 — ADR-043: Upravljanje SMTP redom čekanja i neisporučenim porukama

Sada projektiramo **Mail Delivery Manager**, administratorski modul koji omogućuje praćenje odlaznih e-mailova, pregled SMTP reda čekanja, analizu pogrešaka i kontrolu ponovnih pokušaja isporuke.

Važan princip: **Postfix ostaje jedini autoritet za SMTP red čekanja i ponovne pokušaje isporuke.** Webmail neće razvijati vlastiti paralelni SMTP queue.

### 2. Statusi isporuke

Jedna poruka može imati više primatelja s različitim statusima. Zato ćemo pratiti isporuku **po primatelju**, a ne samo na razini poruke.

| Status | Značenje |
|---|---|
| `accepted` | Postfix je prihvatio poruku |
| `queued` | Poruka je u redu čekanja |
| `deferred` | Privremena pogreška, Postfix će pokušati ponovno |
| `delivered` | Sljedeći SMTP poslužitelj ili lokalni sustav potvrdio je prihvat |
| `bounced` | Trajna neisporuka |
| `expired` | Postfix je odustao nakon isteka razdoblja pokušaja |
| `unknown` | Nema dovoljno podataka za pouzdano utvrđivanje statusa |

**Važno:** `delivered` ne znači da je primatelj pročitao poruku niti da je ona završila u Inboxu. Znači samo da je relevantni sustav potvrdio prihvat.

### 3. Administratorske operacije

| Operacija | Ovlast |
|---|---|
| Pregled vlastitih statusa slanja | User |
| Pregled reda za dodijeljenu domenu | Admin, ograničen na provjerljivo pripadajuće poruke |
| Pregled globalnog reda | Super Admin |
| Ponovni pokušaj deferred poruka | Super Admin |
| Stavljanje poruke na Hold | Super Admin |
| Oslobađanje poruke s Holda | Super Admin |
| Brisanje poruke iz reda | Super Admin + dodatna potvrda |

Sve privilegirane operacije izvršava `mail-admin-agent`, uz audit i ponovnu provjeru stvarnog stanja Postfixa.

Dodatno moramo paziti da Postfix queue ID može biti ponovno iskorišten. Zato ćemo povezivati zapise s vremenskim oznakama, instancom Postfixa i drugim dostupnim identifikatorima, umjesto da samo queue ID smatramo trajno jedinstvenim.

### 4. Monitoring i upozorenja

Predlažem početna pravila koja ćemo kasnije prilagoditi stvarnom prometu.

| Događaj | Reakcija |
|---|---|
| Nagli rast deferred poruka | Upozorenje |
| Poruka čeka dulje od 30 minuta | Informacija administratoru |
| Više uzastopnih SMTP 5xx odbijanja | Upozorenje |
| Veliki rast queuea | Kritično upozorenje |
| Postfix queue nedostupan | Kritično upozorenje |
| Neuspjela administrativna operacija | Audit + upozorenje |

Ovi pragovi nisu produkcijske postavke dok ih ne potvrdimo testiranjem.
