## Korak 78 — ADR-078: Mailbox kvote, kapacitet pohrane i upozorenja

Sada definiramo kako će Webmail nadzirati zauzeće poštanskih sandučića i spriječiti da rast e-mailova, privitaka i lokalnih indeksa ugrozi postojeći mailserver.

Već smo u ADR-035 usvojili centralni Storage Manager koji ograničava pozadinsku obradu kada ponestaje prostora.

**ADR-078 razlikuje dvije stvari:** kvotu pojedinog mailboxa i stvarno slobodan prostor na serveru.

### 2. Što ćemo mjeriti?

| Resurs | Autoritativni izvor |
|---|---|
| Zauzeće mailboxa | Dovecot |
| Kvota mailboxa | Dovecot konfiguracija / QUOTA |
| Slobodan prostor diska | Operacijski sustav |
| PostgreSQL veličina | PostgreSQL |
| Lokalni `.eml` i privitci | Storage Manager |
| Privremeni podaci | Docker volumeni / Storage Manager |
| Backup pohrana | Backup sustav |

Webmail neće računati mailbox kvotu zbrajanjem veličina poruka iz PostgreSQL indeksa jer takav izračun ne mora odgovarati stvarnom zauzeću u Dovecotu.

Prije implementacije provjerit ćemo je li Dovecot QUOTA podrška omogućena i kako je konfigurirana u tvojoj instalaciji.

### 3. Predloženi pragovi upozorenja

| Zauzeće mailboxa | Reakcija |
|---|---|
| Ispod 80 % | Normalno stanje |
| 80 % | Informativno upozorenje |
| 90 % | Upozorenje korisniku i administratoru |
| 95 % | Kritično upozorenje |
| 100 % | Prikaz prekoračenja kvote i uputa korisniku |

Ovi pragovi vrijede za mailboxe s definiranom kvotom. Ako kvota nije postavljena, Webmail prikazuje stvarno zauzeće, bez izmišljenog postotka.

Za slobodan prostor hosta koristit ćemo zasebne pragove iz Storage Managera, uključujući automatsko smanjivanje historical backfilla i obrade privitaka.

### 5. Upravljanje kvotama

Predlažem granularne ovlasti:

| Uloga | Mogućnost |
|---|---|
| User | Pregled kvote i zauzeća vlastitog/dostupnog mailboxa |
| Admin | Pregled zauzeća mailboxa svojih domena |
| Super Admin | Pregled i kontrolirana promjena kvota |

Promjene stvarnih kvota moraju ići kroz Mail Admin Agent, uz validaciju, audit i potvrdu da ih je Dovecot prihvatio.

Korisnici zajedničkog mailboxa vide istu kvotu, jer se radi o jednoj fizičkoj pohrani.

**Važno:** automatsko čišćenje zbog nedostatka prostora nikada neće brisati aktivne e-mailove iz Dovecota. To ostaje pravilo iz ADR-035.
