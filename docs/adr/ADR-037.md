### Pravila obrade

| Situacija | Postupanje |
|---|---|
| Čist privitak | Dostupan za pregled i preuzimanje |
| Otkriven malware | Karantena i blokiranje pristupa |
| Antivirus nedostupan | Privitak ostaje nedostupan dok se skeniranje ne dovrši |
| Nepoznat tip datoteke | Ograničeni pregled, bez izvršavanja sadržaja |
| PDF/DOCX/XLSX | Izolirana ekstrakcija bez izvršavanja makronaredbi |
| Prevelika datoteka | Odbijanje prije završetka uploada |
| Zaštićena arhiva | Poseban status — nije moguće potvrditi sigurnost sadržaja |

Antivirusno skeniranje ne jamči otkrivanje svih prijetnji. Zato su izolacija Document Workera, siguran pregled HTML-a i sprječavanje izvršavanja privitaka jednako važni.

### Posebno pravilo za postojeći Docker Mailserver

Nećemo uvoditi drugi antivirusni proces bez provjere postoje li već ClamAV ili drugi skeneri u mailserver stacku.

Ako već postoji ClamAV, predlažem dijeljenje njegovog skenerskog servisa preko interne Docker mreže, uz kontrolu opterećenja i dostupnosti.
