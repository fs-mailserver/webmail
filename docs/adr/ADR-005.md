## Original pre-approval proposal


### ADR-005: Organizacija i izolacija podataka

U tvojoj specifikaciji predviđene su tablice `users`, `accounts`, `folders`, `threads`, `messages`, `attachments` i druge.

Zadržao bih taj model, uz nekoliko važnih nadogradnji:

| Područje | Arhitektonsko pravilo |
|---|---|
| Korisnici | Jedan korisnik može povezati više mailboxa |
| Mailboxi | Svaki račun ima vlastitu konfiguraciju i pristupna prava |
| Poruke | Puni tekst i metapodaci u PostgreSQL-u |
| IMAP identitet | Account + folder + UIDVALIDITY + UID |
| Threadovi | Grupiranje preko `Message-ID`, `References` i `In-Reply-To` |
| Privitci | Datoteke na disku, metapodaci u PostgreSQL-u |
| Pretraga | PostgreSQL `tsvector` + GIN indeksi |
| Sinkronizacija | Trajno spremljeni checkpointi po mapi |

**Važna dopuna:** poruka koja postoji u dvije IMAP mape ne mora biti spremljena kao dva potpuno odvojena sadržaja. Predlažem razdvajanje logičke poruke od njezinih pojavljivanja u mapama, čime se izbjegava nepotrebno dupliciranje tijela i privitaka.
