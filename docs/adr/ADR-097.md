## Korak 97 — ADR-097: Navigacija, organizacija radnog prostora i personalizacija

Sada projektiramo kako će korisnik svakodnevno raditi u novom Webmailu.

Želimo da korisnik s jednim mailboxom ima jednostavno sučelje, dok korisnik s deset mailboxa može učinkovito upravljati svim porukama, mapama i razgovorima.

Naša osnova već je definirana:

- **ADR-023:** responzivno sučelje s tri panela.
- **ADR-047:** Unified Inbox za više mailboxa.
- **ADR-050:** prilagodljivi tipkovnički prečaci i Command Palette.
- **ADR-096:** centralni Design System.

### 2. Organizacija navigacije

Predlažem dva dijela sučelja.

**Glavni navigacijski izbornik** omogućuje prelazak između pošte, kontakata, kalendara, zadataka, obavijesti i postavki.

**Bočni panel pošte** prikazuje mailboxe, mape, spremljene pretrage, oznake i broj nepročitanih poruka.

Tako korisnik može promijeniti mailbox bez napuštanja glavnog radnog prostora.

### 3. Prilagodbe radnog prostora

| Postavka | Mogućnosti |
|---|---|
| Položaj pregleda poruke | Desno, dolje ili isključeno |
| Širina panela | Korisnički podesiva |
| Gustoća prikaza | Compact, Comfortable |
| Grupiranje poruka | Razgovori ili pojedinačne poruke |
| Zadani Inbox | Unified ili odabrani mailbox |
| Redoslijed mailboxa | Ručno sortiranje |
| Omiljene mape | Prikvačene na vrhu |
| Tema | Light, Dark, System |
| Tipkovnički prečaci | Prilagodljivi |
| Jezik i vremenska zona | Prema ADR-094 |

Postavke se spremaju u PostgreSQL za svakog korisnika i sinkroniziraju između njegovih uređaja.

### 5. Sigurnost personalizacije

Korisničke prilagodbe ne smiju mijenjati prava pristupa.

Primjerice, korisnik može prikvačiti zajednički mailbox među favorite, ali ako izgubi pristup tom mailboxu, on odmah nestaje iz njegova aktivnog radnog prostora.

Također, prilagodbe ne smiju onemogućiti WCAG 2.2 AA pravila iz ADR-095.
