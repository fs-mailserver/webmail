## Korak 41 — ADR-041: Upravljanje domenama, DNS zapisima i DKIM ključevima

Sada projektiramo **Domain Manager**, administratorski modul koji omogućava dodavanje, provjeru i održavanje e-mail domena iz Webmail sučelja.

Naš cilj je da Super Admin može dodati novu domenu bez ručnog uređivanja konfiguracijskih datoteka, a da Webmail pritom ne radi neovlaštene promjene DNS-a.

### 2. DNS provjere

| Zapis | Što provjeravamo |
|---|---|
| MX | Pokazuje li domena na odgovarajući mailserver |
| A / AAAA | Razrješava li se naziv mailservera ispravno |
| SPF | Ovlašteni SMTP poslužitelji |
| DKIM | Postoji li javni ključ i odgovara li aktivnom ključu |
| DMARC | Politika i poravnanje domena |
| PTR / rDNS | Odgovara li obrnuti DNS izlaznoj IP adresi |
| MTA-STS / TLS-RPT | Opcionalne dodatne sigurnosne postavke |

Webmail će prikazivati očekivane i stvarno pronađene DNS vrijednosti, uz jasna upozorenja kada postoji odstupanje.

### 3. DKIM administracija

Predlažem podršku za generiranje, pregled javnog DNS zapisa i sigurnu rotaciju DKIM ključeva. Privatni ključevi ostaju isključivo u zaštićenoj konfiguraciji mailservera.

Kod rotacije ključa najprije treba objaviti novi javni DNS zapis i provjeriti ga, pa tek onda aktivirati novi ključ za potpisivanje. Prethodni ključ ne uklanja se prije isteka potrebnog prijelaznog razdoblja.

### 4. Dodavanje nove domene

### 5. Odluka ADR-041 — Način upravljanja DNS zapisima
