Kod odabira postojeće datoteke korisnik mora imati pravo pristupa toj datoteci. Kod nove datoteke provjeravaju se njegova Webmail kvota, slobodan prostor i dopuštene vrste sadržaja.

### 3. Pouzdan prijenos velikih datoteka

Predlažem **resumable chunked upload** umjesto jednog velikog HTTP zahtjeva.

| Komponenta | Pravilo |
|---|---|
| Transfer ID | Jedinstven i vezan uz korisnika |
| Chunk veličina | Prilagodljiva konfiguracija |
| Checkpoint | Bilježi potvrđene dijelove |
| Retry | Samo za sigurno ponovljive operacije |
| Integritet | SHA-256 cijele datoteke |
| Privremeni podaci | Ograničena retencija i kvota |
| Završetak | Provjera datoteke prije kreiranja sharea |
| Prekid | Kontrolirano uklanjanje nepotpunih podataka |

Stvarni mehanizam nastavka uploada prilagodit ćemo podržanom Nextcloud WebDAV sučelju i verziji instalacije.

### 4. Sinkronizacija metapodataka

Nećemo lokalno indeksirati cijeli Nextcloud.

Webmail treba dohvaćati mape na zahtjev, uz kratkotrajni cache naziva, veličine, datuma izmjene i identifikatora.

Za provjeru promjena koristit ćemo dostupne WebDAV metapodatke, uključujući ETag gdje je primjenjiv.

**Prije dijeljenja postojeće datoteke obvezna je ponovna provjera njezina identiteta i korisničkih prava.**

### 5. Što ako prijenos ne uspije?

| Situacija | Ponašanje |
|---|---|
| Korisnik izgubi internet | Prijenos se može nastaviti ako je sesija valjana |
| Nextcloud ne odgovara | Pauza, ograničeni retry i poruka |
| Istekne autorizacija | Zaustavljanje i ponovno povezivanje |
| Nema prostora | Jasna greška, bez SMTP slanja |
| Datoteka se promijeni | Ponovna provjera prije dijeljenja |
| Antivirus odbije datoteku | Blokada dijeljenja |
| Korisnik odustane | Otkazivanje i čišćenje nepotpunog uploada |

Slanje e-maila mora ostati odvojeno od samog prijenosa datoteke: dok poveznica nije potvrđeno spremna, Composer ne smije poslati poruku koja se oslanja na nju.

### 6. Sigurnost i kontrola resursa

Odvajamo transfer worker od običnih IMAP i SMTP operacija.

Sustav mora ograničavati broj paralelnih prijenosa, protok i privremenu potrošnju prostora. Korisničke vjerodajnice ne smiju se izlagati browseru.

Za osobni Nextcloud račun nećemo automatski kopirati datoteke u centralnu servisnu pohranu. Takva operacija mora biti izričita i vidljiva korisniku.
