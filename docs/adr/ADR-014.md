### Funkcionalnosti pretrage

| Funkcija | Primjer |
|---|---|
| Puni tekst | `ugovor o najmu` |
| Pošiljatelj | `from:booking.com` |
| Primatelj | `to:info@firma.hr` |
| Naslov poruke | `subject:račun` |
| Datum | `after:2026-01-01` |
| Privitci | `has:attachment` |
| Nepročitano | `is:unread` |
| Određeni mailbox | `account:info@firma.hr` |
| Kombinirani filteri | `from:booking.com has:attachment` |

Pretraga mora poštovati prava iz ADR-008: korisnik smije dobiti rezultate samo iz mailboxa kojima ima pristup.

Za početnu verziju predlažem:

- PostgreSQL `tsvector` i GIN indekse za puni tekst poruka.
- `pg_trgm` za djelomična podudaranja adresa, imena i naslova.
- Keyset paginaciju umjesto velikih `OFFSET` upita.
- Podršku za više jezika, uključujući hrvatski, engleski, španjolski i njemački. Za hrvatski ćemo morati posebno testirati kvalitetu pretrage jer PostgreSQL nema jednaku jezičnu podršku za sve navedene jezike.
- Indeksiranje u pozadinskom workeru, izvan HTTP zahtjeva.
