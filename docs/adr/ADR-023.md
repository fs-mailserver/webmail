### Predložene tehnologije

| Područje | Tehnologija |
|---|---|
| Framework | Next.js App Router + TypeScript |
| UI komponente | shadcn/ui + Tailwind CSS |
| Server state | TanStack Query |
| Lokalno UI stanje | Zustand |
| Virtualizacija | TanStack Virtual |
| Editor | Tiptap |
| Prilagodljivi paneli | react-resizable-panels |
| API tipovi | OpenAPI TypeScript |
| Real-time | WebSocket + TanStack Query cache |
| Offline/PWA | Service Worker + ograničeni lokalni cache |

### Važna pravila

**TanStack Query** upravlja podacima s FastAPI-ja: porukama, threadovima, mapama i statusima sinkronizacije.

**Zustand** upravlja isključivo lokalnim stanjem sučelja: odabranim računom, otvorenim editorom, veličinama panela i postavkama prikaza.

WebSocket događaji osvježavaju TanStack Query cache. Nakon prekida veze frontend dohvaća propuštene događaje prema ADR-013.

Za liste s više od 50.000 poruka koristimo virtualizaciju i cursor paginaciju. Ne učitavamo sve poruke odjednom.
