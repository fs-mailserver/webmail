## Korak 33 — ADR-033: Početno indeksiranje postojećih mailboxa

Sada trebamo definirati kako novi Webmail prvi put učitava sve postojeće poruke iz Docker Mailservera.

Ovo je posebno važno jer **ne želimo migrirati ili premještati originalne poruke**. SnappyMail i ostali postojeći klijenti nastavljaju raditi dok novi Webmail gradi svoj indeks.

### Pravila početnog indeksiranja

| Područje | Predloženo pravilo |
|---|---|
| Originalne poruke | Isključivo čitanje preko IMAP-a |
| Redoslijed | Najnovije poruke prve |
| Povijesne poruke | Naknadno indeksiranje u serijama |
| Prekid rada | Nastavak od trajno potvrđenog checkpointa |
| Duplikati | Jedinstveni IMAP identitet i idempotentna obrada |
| Privitci | Pohrana na disk, SHA-256 kontrola |
| Brisanje | Bootstrap ne izvršava IMAP brisanje |
| Opterećenje | Niži prioritet povijesnog indeksiranja |
| Napredak | Postotak i broj indeksiranih poruka u Admin panelu |

Za početno indeksiranje predlažem da worker najprije evidentira UID-ove dostupnih poruka, a zatim ih obrađuje u ograničenim serijama. Događaji koji nastanu tijekom indeksiranja naknadno se usklađuju putem ADR-031.

**Status `sync_completed` smije se postaviti tek kada provjera potvrdi da je indeks usklađen s aktualnim stanjem Dovecota.**
