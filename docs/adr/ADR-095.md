## Korak 95 — ADR-095: Pristupačnost sučelja, tipkovničko upravljanje i WCAG

Sada projektiramo **Accessibility & Inclusive UX Layer**, kojim ćemo osigurati da novi Webmail bude upotrebljiv i osobama koje koriste čitače zaslona, tipkovnicu umjesto miša ili prilagođene postavke prikaza.

To je posebno važno za naš Next.js Webmail s tri panela, naprednom pretragom, Command Palette funkcijom i velikim brojem interaktivnih elemenata.

**Predlažem WCAG 2.2 AA kao cilj pristupačnosti za prvu verziju.**

### 3. Tipkovničko upravljanje

ADR-050 već definira prilagodljive tipkovničke prečace.

U ADR-095 dodajemo pravilo da prečaci ne smiju onemogućiti standardnu navigaciju preglednika ili unos teksta u e-mail editor.

Primjeri:

| Tipka | Ponašanje |
|---|---|
| `Tab` | Sljedeća interaktivna kontrola |
| `Shift + Tab` | Prethodna kontrola |
| `Enter` | Aktiviranje odabrane kontrole |
| `Escape` | Zatvaranje dijaloga gdje je primjereno |
| `Arrow Up / Down` | Kretanje kroz podržane liste |
| Prilagodljivi prečaci | Prema ADR-050 |

Prečaci moraju imati mogućnost isključivanja ili promjene, a aplikacija mora prepoznati kada korisnik piše u tekstnom polju.

### 5. Provjera prema WCAG 2.2 AA

WCAG 2.2 službeni je W3C standard pristupačnosti. Razina AA uključuje sve primjenjive kriterije razina A i AA. Usklađenost se ne može dokazati samo automatskim testovima — potrebna je i ručna provjera. <Cite refs={["turn452502search0","turn452502search3"]}/>

Predlažem sljedeće kontrole:

| Provjera | Alat ili metoda |
|---|---|
| Automatska analiza | axe-core i Lighthouse |
| React komponente | Pristupačne komponente i testovi |
| Tipkovnica | Playwright E2E testovi |
| Čitač zaslona | NVDA + Firefox/Chrome |
| Mobilna pristupačnost | VoiceOver / TalkBack |
| Kontrast i povećanje | Ručna i automatizirana provjera |
| Višejezičnost | Testovi na svih šest jezika |

Prije produkcijskog GO moramo provjeriti ključne korisničke tokove: prijavu, MFA, čitanje i slanje poruka, pretragu, upravljanje privitcima i administraciju.

### 6. Pravilo za GitHub CI

Pristupačnost će biti sastavni dio kvalitete koda iz ADR-029.

Predlažem da CI blokira PR kada automatizirani test pronađe ozbiljnu regresiju pristupačnosti. Ručni testovi i dalje su obvezni za nove kompleksne komponente.
