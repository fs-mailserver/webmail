### 2. Tri razine blokiranja

| Razina | Ovlasti | Učinak |
|---|---|---|
| Osobna blocklista | User | Filtriranje poruka unutar dodijeljenog mailboxa |
| Domenska blocklista | Admin | Pravila za dodijeljene domene |
| Globalna blocklista | Super Admin | Postfix pravila za cijeli mailserver |

Osobna blocklista ne smije automatski stvoriti globalno Postfix pravilo.

Kod zajedničkog mailboxa promjene koje utječu na sve korisnike zahtijevaju odgovarajuću ovlast upravljanja.

### 3. Predložene korisničke akcije

| Akcija | Ponašanje |
|---|---|
| Mark as Spam | Premještanje poruke u Junk |
| Not Spam | Vraćanje poruke iz Junk mape |
| Block Sender | Dodavanje pošiljatelja na odgovarajuću blocklistu |
| Block Domain | Blokiranje cijele domene uz potvrdu |
| Unblock | Uklanjanje pravila |
| View Reason | Prikaz dostupnih antispam rezultata |

Za osobne filtre koristit ćemo Dovecot Sieve kada je primjereno, uz provjeru kompatibilnosti s postojećim pravilima.

Nećemo automatski prepisivati korisničke Sieve skripte ili postojeću konfiguraciju.
