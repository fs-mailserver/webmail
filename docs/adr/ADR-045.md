## Korak 45 — ADR-045: Korisnički e-mail filteri, Sieve pravila i automatski odgovori

Sada projektiramo **Mail Rules Manager**, modul kojim korisnici mogu definirati što se događa s pristiglim porukama.

### 4. Posebno važno za tvoj mailserver

Na postojećem Docker Mailserveru već koristiš Sieve integraciju za obavijesti o novim porukama.

Zato **ne smijemo zamijeniti aktivnu Sieve skriptu korisničkim filterima**.

Predlažem sljedeće pravilo: Mail Rules Manager upravlja samo svojim dijelom konfiguracije, dok postojeći Sieve webhook i ostala sistemska pravila ostaju sačuvani.

Prije aktivacije potrebno je provjeriti podržava li postojeći Dovecot konfiguracijski model odvojene skripte, `include` ili odgovarajući način povezivanja pravila. Također moramo provjeriti dostupnost ManageSieve funkcionalnosti.

### 2. Što korisnik može konfigurirati?

| Funkcionalnost | Primjer |
|---|---|
| Filter po pošiljatelju | `booking.com` → mapa Rezervacije |
| Filter po naslovu | Sadrži „Račun” → mapa Računi |
| Filter po primatelju | `rezervacije@...` → mapa Rezervacije |
| Više uvjeta | Svi uvjeti ili barem jedan |
| Akcije | Premjesti, kopiraj, označi ili odbaci uz ovlast |
| Prioritet | Promjena redoslijeda filtera |
| Vacation | Automatski odgovor tijekom odsutnosti |
| Aktivacija | Uključivanje i isključivanje pojedinog pravila |

Kod zajedničkih mailboxa pravila vrijede za cijeli mailbox. Zato njihovo uređivanje zahtijeva odgovarajuću ovlast `manage_rules`, a ne samo pravo čitanja.

### 3. Zaštita postojećeg Sieve webhooka

Ovo je najvažniji dio ADR-045.

Dovecot Pigeonhole podržava odvojene sistemske i korisničke Sieve skripte te njihovo izvršavanje određenim redoslijedom. ManageSieve omogućava upravljanje korisničkim skriptama. <Cite refs={["turn181562search1","turn181562search11"]}/>

Predlažem odvojiti:

- **Sistemska pravila:** postojeći webhook, obvezne sigurnosne funkcije i integracije.
- **Korisnička pravila:** filteri i Vacation koje kontrolira Webmail.

Prilikom implementacije provjerit ćemo kako je postojeći webhook integriran u Dovecot 2.4 i kako osigurati da korisnički `stop`, `discard` ili `redirect` ne zaobiđu potrebne sistemske događaje.

Nećemo mijenjati postojeće aktivne Sieve skripte bez testiranja njihove kompatibilnosti.
