## Korak 38 — ADR-038: Sigurnost HTML poruka i zaštita od phishinga

Sada definiramo kako će Webmail sigurno prikazivati HTML e-mailove, vanjske slike i poveznice.

Ovo je posebno važno jer HTML poruke mogu sadržavati skriveno praćenje korisnika, lažne poveznice i potencijalno opasan sadržaj.

### Sigurnosna pravila

| Funkcionalnost | Predloženo ponašanje |
|---|---|
| JavaScript u poruci | Zabranjen |
| HTML obrasci | Onemogućeni |
| Vanjske slike | Blokirane prema zadanim postavkama |
| Tracking pixeli | Blokirani |
| CSS | Sanitiziran i ograničen na prikaz poruke |
| `iframe` unutar poruke | Uklonjen |
| `cid:` slike | Prikaz samo provjerenih internih privitaka |
| Sumnjive poveznice | Upozorenje prije otvaranja |
| HTML privitci | Ne izvršavaju se u kontekstu Webmaila |
| Phishing prijava | Akcija *Report phishing* |

Posebno predlažem da prikaz HTML poruka koristi izoliranu domenu ili sandbox bez `allow-same-origin` i bez `allow-scripts`, uz strogi Content Security Policy.

Time dodatno smanjujemo rizik da zlonamjerna poruka pristupi sesiji korisnika.

### Zaštita vanjskih slika

U izvornom `SPEC.md` predvidio si proxy za vanjske slike. To ćemo zadržati, ali proxy mora imati zaštitu od SSRF napada: dopuštene samo HTTP(S) adrese, bez pristupa internim IP adresama, metapodacima servera ili Docker mrežama, uz ponovnu provjeru svakog preusmjeravanja.

Slike se ne učitavaju dok korisnik to izričito ne zatraži.
