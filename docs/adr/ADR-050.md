## Korak 50 — ADR-050: Tipkovnički prečaci i Command Palette

Sada projektiramo jedan od najvažnijih dijelova korisničkog iskustva: **upravljanje e-mailom gotovo potpuno preko tipkovnice**, slično Superhumanu.

Cilj je omogućiti brz rad bez stalnog korištenja miša, ali zadržati potpuno funkcionalno sučelje za korisnike koji preferiraju miš ili dodirni zaslon.

### 1. Command Palette

Predlažem centralni izbornik naredbi koji se otvara kombinacijom `Ctrl + K` na Windowsu/Linuxu ili `⌘ + K` na macOS-u.

### 2. Predloženi prečaci

| Prečac | Akcija |
|---|---|
| `C` | Nova poruka |
| `R` | Odgovori |
| `A` | Odgovori svima |
| `F` | Proslijedi |
| `E` | Arhiviraj |
| `Del` | Premjesti u Trash |
| `J` / `K` | Sljedeća / prethodna poruka |
| `U` | Označi nepročitano |
| `S` | Zvjezdica |
| `/` | Pretraživanje |
| `Ctrl/⌘ + K` | Command Palette |
| `Ctrl/⌘ + Z` | Undo, gdje je dostupan |
| `?` | Prikaži pomoć za prečace |

Prečaci s jednim slovom djeluju samo kada korisnik nije unutar polja za unos, uređivača poruke ili drugog interaktivnog elementa.

### 3. Sigurnost i ponašanje

Predlažem četiri pravila:

- **Nema opasnih globalnih prečaca.** Trajno brisanje uvijek zahtijeva dodatnu potvrdu.
- **Provjera konteksta.** Prečaci se ne aktiviraju tijekom pisanja e-maila.
- **Provjera ovlasti.** Command Palette prikazuje ili omogućava samo radnje za koje korisnik ima pravo.
- **Pristupačnost.** Sve naredbe dostupne su i mišem; korisnik može isključiti tipkovničke prečace.

Command Palette neće zaobilaziti FastAPI autorizaciju. Ona je samo dodatno korisničko sučelje za postojeće API operacije.

### 4. Personalizacija

Predlažem da se korisničke postavke pohranjuju u PostgreSQL i sinkroniziraju između uređaja.

To uključuje odabrani stil prečaca, uključivanje ili isključivanje prečaca te eventualne korisničke prilagodbe.
