### 5. Sigurnosni negativni testovi

Posebno inzistiram na provjeri da aplikacija pravilno odbija nedopuštene radnje.

| Scenarij | Zahtjev |
|---|---|
| Korisnik mijenja `user_id` u zahtjevu | Nema eskalacije ovlasti |
| Korisnik mijenja `mailbox_ref` | Nema pristupa tuđem mailboxu |
| Opoziv tijekom Celery posla | Provjera prava prije vanjskog učinka |
| Ukraden ili zastario session cookie | Odbijen kad je opozvan/istekao |
| Brute-force prijave | Rate limiting |
| Ponovljeni recovery zahtjevi | Ograničavanje i audit |
| Zlonamjerni HTML u prikazu | Ne izvršava se |
| Nevaljan API cursor | Odbijen |
| Krivi `Idempotency-Key` kontekst | Nema pogrešne ponovne uporabe |
| Mock adapter pokušava pristup produkcijskoj adresi | Blokirano mrežnim pravilima |

## 6. Testovi oporavka i otpornosti

Paket 1 još nema stvarnu IMAP sinkronizaciju ni SMTP slanje, ali može testirati oporavak osnovnih servisa.

Predlažem:

| Test | Očekivani rezultat |
|---|---|
| Restart FastAPI-ja | Korisničke sesije ostaju konzistentne |
| Restart Celeryja | Trajni testni poslovi se sigurno nastavljaju |
| Redis nedostupan | Kontrolirana degradacija |
| PostgreSQL nedostupan | Readiness signalizira kvar |
| Audit sustav nedostupan | Kritične promjene blokirane |
| Secret Store nedostupan | Tajne nisu dostupne nezaštićenim putem |
| Pogrešna migracija | Deployment zaustavljen prije aktivacije |
| Backup restore u izolaciji | Baza se može obnoviti bez produkcijskih operacija |

Puni Webmail DR testovi iz ADR-142 provode se u Paketu 5.

## 7. Testovi performansi

U Paketu 1 ne mjerimo rad velikih mailboxa jer još nema stvarnog IMAP adaptera.

Mjerimo osnovne funkcije:

- Latenciju login i session endpointova.
- Trošak WebAuthn i Argon2id provjere.
- Opterećenje PostgreSQL-a pri provjeri autorizacije.
- Broj paralelnih sesija u testnom okruženju.
- Stabilnost API-ja tijekom simuliranih grešaka.

Pragove prihvaćanja definiramo prije izvođenja benchmarka u odnosu na izmjereni kapacitet testnog okruženja.

## 8. Testni dokazi

Za svaki testni skup trebamo zadržati:

| Dokaz | Sadržaj |
|---|---|
| Test Report | Prošli/neprošli testovi |
| CI run | Referenca na izvršavanje |
| Coverage Report | Pokrivenost relevantnih modula |
| Security Scan | Nalazi i ozbiljnost |
| OpenAPI Diff | Kompatibilnost ugovora |
| Migration Report | Rezultat Alembic provjere |
| Isolation Report | Dokaz mrežne izolacije |
| Accessibility Report | Automatski i ručni rezultati |
| Review Report | Neovisna sigurnosna provjera |

Testni izvještaji ne smiju sadržavati tajne, privatne poruke ili nepotrebne osobne podatke.
