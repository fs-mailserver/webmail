# Webmail

Webmail monorepository for an asynchronous FastAPI backend and a planned Next.js frontend.

- `backend/` contains the initial backend, migrations, and tests.
- `frontend/` is reserved for the planned web client.
- [SPEC.md](SPEC.md) describes the architecture and planned features.
- [AGENTS.md](AGENTS.md) documents project conventions and implementation phases.

The backend is an early implementation; mail synchronization, the frontend, and deployment integration are not yet complete.
